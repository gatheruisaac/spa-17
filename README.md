# spa-17
For fulfillment of class assignment spa 17.

spa-17 is a single-page React application for managing and showcasing personal projects.
Built as a lab for the SPA with React.

See the demo here: https://spa-17.vercel.app/

## Features
- Add a new project with a title and description
- Delete any project from the list
- Search and filter projects by title in real time

## Tech Stack
- [React 18](https://react.dev/) — UI library
- [Vite](https://vitejs.dev/) — build tool and dev server
- CSS — custom styling
